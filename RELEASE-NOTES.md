# Revenue Cycle Knowledge Bank — Soft-launch visual refresh

## Release candidate v4: Healthcare Light + Visual Learning

### Design direction
- Replaced the dark dashboard look with a light, clinical, professional healthcare palette: clean whites, pale blue-grey surfaces, healthcare teal, restrained navy, and small gold accents.
- Applied the light palette across the public HTML pages while preserving series-specific accent identities.
- Restyled navigation, cards, forms, mission choices, feedback, and master-plan statuses for stronger contrast and calmer visual hierarchy.

### Visual engagement
- Added the existing Revenue Cycle Knowledge Bank banner to the hero showcase.
- Added simple healthcare-oriented SVG illustrations for the individual, team, and practice pathways.
- Added an interactive visual learning gallery with three existing knowledge graphics: healthcare foundations, claim adjustment reason codes, and CMS-1500.
- Gallery supports topic tabs and previous/next controls, updates its alt text and destination link, and respects reduced-motion preferences.
- Shortened selected page copy so visuals and actions lead the experience.

### Content and safety
- Retained clear Available now / In development / Planned status labels.
- Kept the fictional-data warning and the instruction not to submit real patient information.
- Retained the free core self-learning commitment and distinction for optional paid guided learning/services.
- No external image hosts, stock-photo hotlinks, or third-party GIF services added; the page uses assets already included in the repository.

### Validation performed
- Checked local links and local asset references across all HTML pages.
- Checked homepage inline JavaScript syntax with Node.js.
- Live deployment, browser/device visual QA, and pilot-form email delivery remain to be verified after deployment.
