# Revenue Cycle Knowledge Bank — Soft Launch V6

This is a static-site update based on V5.

## Deploy
- For a complete replacement, use the full ZIP and place the included site files at the repository's publish root.
- For an existing repository, apply the patch ZIP contents at the same relative paths.
- Keep the `images/` directory and all existing assets.
- Test all navigation and form delivery after deployment.

## Email note
The contact form uses Formspree endpoint `https://formspree.io/f/mqpzoqda`. The destination inbox is configured in Formspree, not in this HTML. Verify the recipient and run a test submission before public launch.
