# RKB Soft Launch — Version 6

## Changes
- Updated the global font stack to Aptos / Segoe UI / Arial sans-serif and increased base type size and line-height for readability.
- Added larger visual learning-room tiles with image-like colour panels, stronger hover/focus states, and responsive layout.
- Added a vision hover/focus reveal on the homepage showroom, with a larger-font vision statement.
- Changed the LinkedIn series directory to show only Monday, Tuesday, and Wednesday as published.
- Replaced Thursday, Friday, Saturday, and Sunday archive samples with Work in Progress pages; no sample post content is displayed on those pages.
- Clarified that the contact form uses a Formspree endpoint and that inbox routing/verification cannot be confirmed from the static website.

## Contact form status
`contact.html` posts to the existing Formspree endpoint. That does **not** prove it delivers to the owner's email. Confirm the recipient email and verify the address in the relevant Formspree account, then submit a test from the deployed site.

## Validation
Local HTML structure, links, archive content, and ZIP integrity should be tested before deployment. This package has not been deployed or tested in a live browser.
